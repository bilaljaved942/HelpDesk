# Sizing Guide

## Jackets and tops
Our jackets have an **athletic fit**. If you are between sizes, or want to wear a thick fleece underneath, we recommend sizing up.

| Size | Chest (in) | Waist (in) |
|------|-----------|-----------|
| S    | 35–37     | 29–31     |
| M    | 38–40     | 32–34     |
| L    | 41–43     | 35–37     |
| XL   | 44–46     | 38–40     |
| XXL  | 47–49     | 41–43     |

## Trousers
Trousers come in short (30 in), regular (32 in) and long (34 in) inside-leg lengths.

## Footwear
Our hiking boots run **half a size small**. We recommend ordering half a size larger than your usual shoe size. Trail runners are true to size.

## Kids' sizes
Kids' clothing is sized by age (4–14 years). Kids' items follow the same 30-day return policy.
